# Бот прачечной (ковры, шторы)

Роли: **админ** (ID в `ADMIN_IDS`), **диспетчер**, **курьер**, **цех**.
Заказы нумеруются 1, 2, 3… Карточка: № / имя / номер / адрес.

## Запуск
1. `cp .env.example .env` → впишите `BOT_TOKEN` и `ADMIN_IDS` (через запятую).
2. `./run.sh` (Linux/macOS), `run.bat` (Windows) или `docker compose up -d --build`.
База (`laundry.db`) создаётся сама. Запускайте один экземпляр бота.

## Как работает
- Новый сотрудник пишет `/start` → админ получает кнопки выбора роли (👥 Сотрудники — смена роли/удаление).
- **Диспетчер/админ:** «➕ Новая заявка»: номер → имя → адрес (или сразу 3 строки: имя / номер / адрес). Знакомый номер подставляет имя и адрес.
  **Адрес:** пишете улицу и дом → бот ищет и присылает до 5 вариантов → вы выбираете точный → вводите подъезд/этаж/кв. Адрес и координаты фиксируются.
  Не нашёл? Напишите иначе, пришлите точку на карте (📎 → Геопозиция) или «Оставить как написал».
  Поиск: 2ГИС (если задан `DGIS_KEY`) → Photon → Nominatim, с повтором и кэшем.
- «📋 Заказы», «🔎 Поиск» (№, телефон, имя), ✏️ изменить (адрес — тем же поиском), ❌ отменить.
- **Курьер:** «🟢 Начать смену» → «📍 Геопозиция» → задачи от ближних к дальним, без лимита; «🗺 2ГИС».
  «✅ Забрал» → заказ у водителя → «🏭 Сдать в цех» (всё сразу). Готовые заказы: «🚚 Взял» → «✅ Доставил».
- **Цех:** «🧼 В цехе» или просто номер заказа → «📐 Замеры»: размеры ковров по строкам (3х4 / 4х5 …), затем сколько штор → «✅ Готово».

Статусы: 🆕 Новый → 🚗 У водителя → 🏭 В прачечной → ✅ Готов к доставке → 🚗 У водителя → 📦 Завершён (или ❌ Отменён).

## Render
Нужен тип **Background Worker** (бот работает постоянно) и **Disk** — постоянный диск есть только на платных планах. Без диска файл базы стирается при каждом перезапуске.
1. Выложите папку в GitHub (`.env` и `*.db` в репозиторий не попадают — они в `.gitignore`).
2. Render → New → Blueprint → выберите репозиторий (`render.yaml` настроит всё), задайте `BOT_TOKEN`, `ADMIN_IDS`, `DGIS_KEY` (необязательно).
   Вручную: Background Worker, build `pip install -r requirements.txt`, start `python main.py`, Disk с Mount Path `/var/data`, переменная `DATABASE_URL=sqlite+aiosqlite:////var/data/laundry.db`.

## База: скачать и восстановить
- Админу: кнопка «💾 Бэкап» или `/backup` — бот присылает файл базы. Каждую ночь в 03:00 (Бишкек) копия приходит всем админам сама.
- Восстановить: админ отправляет файл `.db` боту с подписью `/restore` — бот заменит базу и перезапустится. Работает и без диска на Render: после сброса просто отправьте последнюю копию.
